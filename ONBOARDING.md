# NovaCart Cohort Onboarding

Use this checklist to prepare before the cohort starts.

## What You Should Have Ready

- A laptop or desktop you can use for the full cohort
- Reliable internet access
- A GitHub account you can use for cohort work
- A code editor such as VS Code
- A terminal you are comfortable using
- Git installed and working locally

## Recommended Local Tools

These are not all required on day one, but having them installed early will make the first few days easier:

- Python 3.12 or a compatible local Python 3 runtime
- Docker Desktop or a compatible Docker Engine plus Docker Compose
- GitHub CLI (`gh`)
- Azure CLI (`az`)
- Terraform

## Access You May Need During the Cohort

Some access is required later in the program, especially once the Azure weeks begin:

- Permission to clone the cohort repository
- Access to the Azure subscription
- A working Azure CLI login (`az login`) that can reach the assigned subscription

Do not use personal production accounts or share credentials between participants.

## Repository Workflow

Once you receive access to the starter repository:

1. Clone the repository locally.
2. Create your own personal public repository.
3. Push your cohort work to that personal repository as you progress.

Keep your personal repository focused on your own cohort work and do not share credentials or reuse private production access.

## What You Should Be Comfortable Doing

- Reading logs
- Running shell commands
- Editing files in a text editor
- Using Git for branches, commits, and pull requests
- Following written instructions carefully
- Asking for help with evidence when something does not work

## Time Commitment

- Plan for about 2 focused hours on weekdays
- Weekend work will be lighter and used for catch-up, review, and consolidation

## Before Day 1

Before the cohort begins, make sure your basic setup is ready and that you can access the tools you’ll need during the program.

## What the Cohort Will Cover

You do not need to arrive knowing the answers to the technical tickets.

The cohort is designed to help you learn how to:

- understand an unfamiliar application
- package and run it consistently
- build a local environment
- validate changes safely
- move it into Azure
- secure and observe it
- respond to incidents
- justify operational decisions

The tickets will give you the problems to solve. Your job is to investigate, choose the right approach, implement it, and explain why it works.
