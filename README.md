# NovaCart Student Repository

This repository contains the starter application and the onboarding information for the NovaCart DevOps cohort.

## What is included

- `novacart/`: the application starter code
- `ONBOARDING.md`: what participants should prepare before the cohort starts

## Before Day 1

Read [`ONBOARDING.md`](ONBOARDING.md) and confirm your basic setup is ready.

After you get repository access, clone the starter repo locally, create your own personal public repo, and push your cohort work there as you progress.
